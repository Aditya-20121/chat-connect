# Store assets

| File | Shows |
|---|---|
| `01-source-chatgpt.png` | a thread on ChatGPT with the bar over it |
| `02-target-gemini.png` | the file and covering note landing in Gemini |
| `03-target-claude.png` | the same in Claude, with the confirmation toast |

Those are the full-size captures, used in the README.

`listing/` holds the same three padded to **1280x800, 24-bit, no alpha** — the
Chrome Web Store's requirement. They are padded rather than cropped, because
cropping to 16:10 cuts either the bar or the composer out of frame, and those
are the whole point of the picture. The store takes PNG or JPEG only; animated
GIFs are not accepted there, so these are the assets that gate submission.
